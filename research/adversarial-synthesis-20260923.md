# Adversarial synthesis: what survives the four projects

This review tests the strongest versions of hypotheses A–H, rather than adding
them as principles. **No sibling was changed, compiled, refreshed or promoted.**
Historical receipts are inspected evidence, not freshly reproduced acceptance.
Current working-tree observations are separately hashed; they need not describe
one simultaneous state across projects. Old catalogs remain historical snapshots.

Evidence dossiers: [Empires history](adversarial/empires-convergence.md),
[SimAnt reclassification](adversarial/simant.md), [Stunts tooling and frontier](adversarial/stunts.md),
[Icy context and regions](adversarial/icy-regions.md). Their companion JSON files
pin source paths, commits/hashes and observations. The
[whole-Icy census](adversarial/icy-function-census.json) retains all 253 sanitized
function rows and all 25 ledger-referenced report identities.

## A — How generic can recovery become?

**Strongest claim:** one reusable solver, blocker classifier and control plane
can recover historical C across all four toolchains. **REJECTED / TOO STRONG.**
Empires ordered relocations, MSC7 selector/private contributions, Stunts' lost
OMF frame information and Icy's GCC/DWARF/pass evidence have different observables
and proof obligations. Optional JSON fields do not make those semantics portable.

| Layer | Assessment | Evidence and useful boundary |
|---|---|---|
| Experiment methodology | GENERIC METHOD / PLAUSIBLE | Controlled context changes and explicit falsifiers recur; one shared implementation has not demonstrated a recovery speedup. |
| Evidence/provenance representation | ADAPTER-DEPENDENT | Hashes, immutable refs and scoped receipts transfer; reconstructing each native evidence dependency does not follow automatically. |
| Mismatch/residue vocabulary | GENERIC METHOD / PLAUSIBLE | Code, binding, extent, data and neighbor effects recur. Their units and comparison rules stay native. |
| Effective-output clustering | GENERIC AND DEMONSTRATED, at the scoped operation level | Stunts, SimAnt and Icy independently group collapsed outputs. Raw OMF and resolved code/fixup identities are different equivalence relations; normalization needs an adapter. |
| Blocker classification | ADAPTER-DEPENDENT for triage; NOT SUPPORTED as universal causal inference | SimAnt's 75 changed labels and Stunts' 261 multi-category rows defeat a permanent function-to-root-cause mapping. |
| Worker/orchestrator architecture | ADAPTER-DEPENDENT | Research isolation, ownership and promotion serialization exist in different forms. A common lease or mutation protocol has not been demonstrated. |
| Compiler-response representation | ADAPTER-DEPENDENT | Parent/oracle deltas are useful, but complete contributions and protected context cannot be reduced to one similarity score. |
| Analysis-level escalation | GENERIC METHOD / PLAUSIBLE | Multiple successful context/topology interventions support a procedure; deciding the next level still requires evidence. |
| Actual hypothesis generation | COMPILER-SPECIFIC for useful content | A proposer interface is plausible; historical language/ABI/profile rules remain necessary. No tested cross-compiler generator here. |
| Actual C reconstruction | COMPILER-SPECIFIC, with PROJECT-SPECIFIC evidence | External m2c supplies a practical matching-oriented example within its targets. No evidence supports a universal historical-x86 solver. |

**Blocker counterexample.** SimAnt's 438-row current-profile pass has 399
`TRUE_SOURCE_SHAPE_MISMATCH`, 20 ABI, 13 unknown, four body-exact/layout,
one profile-retest and one mirror candidate. Of 27 old TU-context labels,
26 now fall into source-shape residue and one unknown. This does not prove 26
semantic bugs: the fresh category is a deterministic triage decision. A wrong
`DrawEdit` target binding also explains a case previously susceptible to a vague
context diagnosis. Two stale profiles and 17 multi-label histories further
undermine immutable labels.

**Narrow conclusion — GENERIC METHOD:** classify the tuple *(target, candidate,
compiler/context, evidence, tooling, proof capability)*. Keep observed residue,
supported causal mechanism, rejected mechanism, unresolved dimension and
workflow/capability block separate and potentially simultaneous. Register-only
or BP-offset differences do not establish a register-allocation cause.
See [recovery levels and response maps](../knowledge/recovery-levels.md).

**Confounder:** improved classification can merely rename ignorance.
**Next falsifier:** blind-replay old candidates under frozen current evidence;
measure whether the new representation selects fewer redundant tests or yields
more independently justified outcomes than the old labels. If it does neither,
the taxonomy has not earned its cost.

## B — Why did Empires converge while Icy retains a hard tail?

**Strongest claim:** Empires became easy once bootstrapped, because its compiler
was simpler and its recovery monotonic. **REJECTED / TOO STRONG.** The evidence
supports several narrower explanations, not a controlled causal ranking.

Empires began with an imported inventory of 126 matching C, 20 matching ASM
and 35 known-library entries; its initial audit freshly rebuilt 125 C and all
20 ASM entries, refusing one stale receipt. This is a material seed-quality
confound. At `e5b79736fcacbb2000444c1342c63ab07b4068ba`, the **structural experiment**
was already file/ordered-relocation exact, while the ordinary candidate was not:
4,012 RAW-owned bytes, 13,932 synthetic DATA bytes, 37,252 synthetic BSS bytes
and seven topology adapters remained. Raw ownership reached zero before those
adapters did. At `b4a0fc076372fb86387a3cdcede8485faa7d38a5`, four adapters and
12 OMF-adapter owners still remained. Source closure at
`e56855c647051b53b5c62fea134a7b8d4af84770` achieved a natural one-link route,
106 ordered relocations and zero synthetic/raw/adapters/transforms.

Thus **B1 survives as PROJECT FACT:** artifact equality preceded source/topology
closure. Calling the later work merely cosmetic cleanup is false. Zero raw,
zero unresolved symbols, zero adapters and natural construction were reached
at different milestones. Closure permits supported ASM/runtime representations;
it neither proves unique original source nor that the game was wholly C.

**B2 survives locally:** discrete mechanisms had strong observables. GAME's
eight-member, 4,146-byte TU explains unchanged neighbors through BOOTSEED's
inline ASM selecting whole-TU `-B`; extending that route to HITTEST fails.
MUSIC's documented 700-byte module matched code but had wrong fixup order
until structured C removed the inline-ASM/TASM route. These are falsifiable
route/topology discoveries. There is no defensible total count of all
high-fan-out discoveries or their independent contributions to completion.

**B3 needs narrowing:** the accepted structural route could remain exact while
construction debt was retired. Other Empires diagnostic routes remained
nonexact. Stunts independently preserves HYBRID_EXACT during C-owner substitution
(historical 252 → 328 → 408 C bytes with raw bytes falling correspondingly).
Therefore this invariant is useful but does not alone explain convergence.
Icy also protects accepted state through transactions; historically better
source hypotheses can fail admission because unchanged peers regress.

**B4 is strongly supported as PROJECT FACT:** Icy's ledger report population is
heavily selected by function size. All 25 referenced report hashes matched
their ledger at capture, with 253 unique function VAs.

| Icy report population | Functions | Original function bytes | Mean / median size |
|---|---:|---:|---:|
| FUNCTION_MATCH | 209 | 41,876 | 200.36 / 86 |
| Nonexact: 42 DIFFER + 2 CODEGEN_SIMILAR | 44 | 83,765 | 1,903.75 / 1,104.5 |
| Total | 253 | 125,641 | — |

Count completion is **82.61%**, byte completion **33.33%**. The largest
1/2/5/10 unresolved functions contain **20.80/30.97/46.79/62.76%** of unresolved
bytes. `play` (17,420) plus `draw_frame` (8,518) contain 25,938 bytes.
These are function-report bytes, not whole-PE closure percentages; no comparison
to Empires' executable percentage is valid. This is hard-tail selection, not
proof of model or compiler inferiority.

**B5 survives as scoped sensitivity, not a universal conditioning claim.**
An unchanged Icy play body grows 17,400 → 17,497 under the prototype-generating
TU wrapper; current-order/no-prototype control reproduces 17,400. A draw status
variant shrinks 8,203 → 8,137 but loses two unchanged exact peers. The compiler
pass receipt locates seven-to-six `new_rand` call convergence at `181r.csa`.
The dramatic uninitialized-`playing` deletion at `524a8a21347b2a410fbe8bb9764a0a3958177000`
is an incomplete/undefined-source warning, **not evidence that two valid
equivalent sources are chaotically separated**. Stunts' far-alias removal
predictably shrinks 190 → 172 bytes, but its own TU control changes call/fixup
behavior with an unchanged body. Old compilers are not uniformly local either.

**Next falsifier:** paired, semantically supported region/context interventions
with complete peer measurements. Until then, neither “GCC is the main problem”
nor “only giant functions remain” explains all Icy misses.

## C — Project stage versus model quality

**Strongest claim:** larger Claude-era breakthroughs show higher model ability.
**NOT SUPPORTED.** Seed quality, harness, evidence, tool availability, runway,
selected remaining tasks and model attribution all confound the comparison.
Git authors or model co-author trailers do not identify the exact reasoning,
tools, cost or counterfactual needed for a capability estimate.

SimAnt's documented expert pass promoted 13 functions (230 → 243), including
six dialog cases after two private arrays, four map cases, two yard cases and
one common-store repair. It mixes mechanisms and semantic repairs; the
four-member map TU was rejected and only three members were supported. This
demonstrates stage-dependent opportunities without attributing them to a model.
Icy's verified pre-TU_CONTEXT snapshot already documents a peer regression
forcing a reconstruction back to a stub. Empires' imported seed further changes
the starting problem. A later model at an earlier snapshot might benefit from
these opportunities; the size of that benefit is **unmeasured**.

The existing [matched Stunts review](fleet/evaluation.md) remains the only
controlled local routing evidence: four selected pairs, equal strict solve
counts, no new production recovery, 1.32x hypothesis effort and 64.17x direct
scenario-cost ratio. It does not estimate early-versus-late stage effects,
population model equality or Sol's value.

**Narrow conclusion — WORKING HYPOTHESIS:** stage explains some apparent
throughput differences; the fraction is unidentifiable from these histories.
Use the [three frozen replay proposals](../docs/historical-replay.md), including
pre-topology SimAnt and pre-atomic-TU Icy. Sanitized exports must hide future
Git objects and artifacts, not merely detach a worktree. No comparison was run.

## D — Can giant functions become independent recovery regions?

**Strongest claim:** existing region files already partition play/draw into
safe independent worker tasks. **REJECTED / TOO STRONG.** They constitute an
implicit evidence/authoring architecture, not an established independence proof.

There are six declared play source spans and four draw spans, separate from
43 historical play machine chunks covering all 17,420 original bytes. Existing
`line_budget.py --regions` already compiles a whole TU and attributes candidate
instruction budgets; `local_slot_trace.py` reports slot reads/writes and reuse.
Neither establishes complete live-ins/live-outs or a bijection from source to
machine regions. DWARF lexical ranges are often noncontiguous: play has 11 such
blocks, draw 27. Dominator/postdominator SESE candidates, natural loops,
lexical/lifetime boundaries and call phases could propose regions; only CFG
and interface evidence can establish their actual boundaries.

The new [read-only inventory](../knowledge/large-function-regions.md) found a
freshness failure: draw's final declared source span ends at line 586, while
the retained merged body has 545 lines. Its mapping is withheld. Play's spans
fit 1,667 lines but still lack a sidecar-to-body hash. This directly falsifies
using existing sidecars as ready-made independent task authority.

Three different couplings must remain distinct:

| Observation | Interpretation | What it does not prove |
|---|---|---|
| W1b writes `midY`, W2 contains its only readers | Semantic cross-region dependence; writes can disappear before consumers are reconstructed | An arbitrary source-phase split is a closed task |
| Draw edit loses `show_instructions` and `stopGameMusic`; unchanged play changes under a wrapper | Measured compiler/context coupling at whole-TU scope | Precise register/pass cause, or independence of other regions |
| Closing a multiline comment changes attributed W1b budget; inlining misattributes select_profile instructions | Measurement/annotation coupling | Real emitted-code improvement |

**Narrow conclusion — GENERIC METHOD:** make region a first-class *research
scope*, with source identity, possibly disjoint instruction sets, evidence,
interfaces and protected dependencies. **WORKING HYPOTHESIS:** some regions
will prove independently grindable. Region diagnostic states are orthogonal
facts, never `FUNCTION_MATCH`. Missing liveness remains null. The prototype
retains calls/data/slot counts and curated influences without fabricating a CFG.

**Next falsifier:** the five-compile baseline/no-op/A/B/A+B influence experiment
specified in the region guide, using authentic whole-function/TU construction.
If supported edits routinely cross boundaries or fail to compose, retain regions
for analysis but not concurrent independent task ownership.

## E — Dynamic recovery unit: hierarchy or graph?

**Strongest claim:** expression → region → function → TU → link is a universal
escalation tree. **REJECTED / TOO STRONG.** Empires MUSIC changes link topology
through a source representation; SimAnt private data and symbol binding cross
body/unit boundaries; Icy peer effects cross function ownership. A fixup connects
site, target, frame and data owner. A compiler profile qualifies an experiment
and can differ across objects or functions; it is not a fixed tree node.

**Narrow conclusion — CROSS-PROJECT PATTERN:** successful investigations change
scope when local tests stop discriminating. **GENERIC METHOD:** represent a
graph with separate edit, compilation, measurement, protected and acceptance
scopes. Data ownership, evidence provenance and tool/profile context are
orthogonal dependencies. Scope escalation is a reasoned new question, not a
mandatory march to larger scopes. A stale binding may require revisiting a
smaller symbol fact rather than a whole-TU search.

**Next falsifier:** encode the MUSIC, SimAnt binding and Icy peer transactions
without losing any native proof obligation. If a proposed shared graph cannot
express an obligation, extend the adapter or retain its opaque evidence—not
the claim that the graph completely describes recovery.

## F — Has mechanism transfer into Stunts failed?

**Strongest claim:** the SUPERVISOR population proves transfer remained prose.
**REJECTED / TOO STRONG.** Current Stunts has fresh multi-category
`blocker_census.py`, frozen-body `tu_context.py`, an Empires-inspired
`audit_function_extents.py`, binding fixtures, output families and guarded
promotion. Inspecting code changes the conclusion drawn from old summaries.

The current 602-task queue is entirely SUPERVISOR; only 220 entries have verified
boundaries/instruction anchors. **382/602 (63.46%) lack that verified boundary
state.** Categories overlap: 143 instruction-evidence gaps, 127 unknown binding
modes, 121 binding candidates, 35 TU/context candidates and 34 data-ownership
cases. 261 tasks have multiple categories. These are not mutually exclusive
causes, estimated solve rates or proof of one common missing capability.
The retained PASS workflow fingerprint differs from the current queue's: it
cannot be represented as freshly verifying the whole current state.

Stunts TU controls include a 62-byte target unchanged under known neighbors
(negative control), and a synthetic unchanged 16-byte target whose helper context
changes call bytes and fixup type (positive control). Strict acceptance is
NOT_EVALUATED. Extent review flags four suspect ranges among 234; one imported
94-byte interval includes nine bytes beyond RETF with another prologue.

**Narrow conclusion — GENERIC METHOD:** transfer experimental contracts and
native capabilities, not compiler-specific causes. The next useful work is
fresh retesting of selected old blockers, original ownership/binding evidence,
one needed historical LINK differential, and complete-contribution/protected-peer
accounting for TU probes. Stunts' single-public-at-zero binder restrictions are
real proof boundaries. SimAnt selector pools and Empires frame rules are not
portable implementations. A universal scaffold composer is premature.

**Next falsifier:** a preregistered verified-boundary cohort must show that one
specific missing native capability explains a strict admissibility gap. Count
classification changes, newly eligible work and actual promotions separately.

## G — Is there a compiler gradient?

**Strongest claim:** a smooth local score gradient guides historical source
recovery. **REJECTED / TOO STRONG.** SimAnt/Stunts output collapse creates
plateaus; Icy late-pass merging removes apparently different hypotheses;
Empires route changes affect ordered fixups with identical code. Draw improves
target size while losing exact neighbors. No scalar derivative captures these.

**Narrow conclusion — GENERIC METHOD:** use an **empirical compiler response
map**: an intervention, its frozen context, candidate-minus-parent changes,
candidate-versus-oracle residue, output equivalence class, controls and remaining
uncertainties. A causal edge requires a discriminating controlled comparison;
an association is not a mechanism. “Compiler gradient” may remain a historical
metaphor for structured feedback only, without monotonicity or directionality.

**Next falsifier:** compare response-map selection against score-only selection
on archived native batches; measure redundant choices and preservation of
tradeoffs. A nicer representation without improved decisions is not a result.

## H — Generic control plane, rather than universal decompiler?

**Strongest claim:** a generic research operating system can own everything
except the compiler executable. **REJECTED / TOO STRONG.** Proof, fixup meaning,
TU construction, ownership, safe output equivalence and transaction boundaries
are not interchangeable plugins behind an unqualified `compile()` call.

**Narrow conclusion — WORKING HYPOTHESIS:** a small research/control layer is
better supported than a universal solver. It can store provenance, hypotheses,
scoped responses, negative evidence, context-qualified output classes, costs,
task metadata and compressed reports. Adapters retain ABI/format semantics,
historical invocation, source/TU construction, data ownership, identity rules,
native transaction/locking and strict acceptance. A shared layer must preserve
native receipts and unknowns; it cannot infer causality or authorize promotion.

**Counterexamples to overgenericity:** Empires relocation ordering cannot be
sorted away; SimAnt byte-equal bodies can lack private ownership; Stunts MZ
evidence cannot recover missing OMF frame methods; Icy line budgets can change
through annotations without a code improvement. Even orchestration is native:
SimAnt compile locks do not claim a task throughout model reasoning.

The [external audit](../knowledge/ecosystem.md) supplies real components:
m2c matching-oriented source recovery, decomp-permuter candidate transformation,
compilation/scoring/parallel search, objdiff and other native diff feedback,
and Mizuchi's model/compiler iteration. None was demonstrated in this audit to
provide the complete historical-x86/TU/layout ownership and proof workflow.
Learn from/reuse those bounded capabilities when an adapter experiment justifies
it; this review adds no external dependency or scheduler.

**Next falsifier:** lossless archived-response replay across two native projects
plus a measured reduction in supervisor work. Failure to preserve distinctions
or reduce repeated reasoning argues against expanding the control plane.

## Decisions and the next three experiments

Retain exact independent acceptance, scoped provenance, controlled interventions,
explicit partial proof, output collapse and mechanism-to-capability transfer.
Narrow blocker taxonomy, context escalation and regions as described above.
Reject universal causal labels, smooth gradients, automatic region independence,
throughput-based model ranking and the claim that Stunts lacks all transferred
tools. Large cheap fleets, exceptional-only Astra, independent regions and a
cost-saving shared control plane remain hypotheses.

1. **Icy region influence:** repair/hash-bind metadata in its owning project,
   then five controlled whole-TU compilations. Distinguish semantic, compiler
   and measurement effects; protect every currently exact peer. This determines
   whether region scheduling is justified at all.
2. **Stunts fresh blocker/capability cohort:** fixed verified-boundary targets,
   fresh context-qualified classification and one discriminating native
   profile/TU/binding intervention per supported family. Reuse current tools;
   require full native proof before counting promotions.
3. **Historical replay:** first run an inexpensive feasibility/receipt audit
   of the three exact snapshots in the replay guide, then separately authorize
   a matched model/harness trial. Measure new strict output and independently
   validated mechanism fan-out; prevent future-solution leakage.

The smallest implementation delivered here is the read-only region inventory,
not an autonomous region solver. The existing compact response/fleet contracts
remain the smaller cross-project integration hypothesis to validate before
building distributed infrastructure.
