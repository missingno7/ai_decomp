## A supervisor label is not a causal diagnosis

The captured queue has **602 SUPERVISOR** tasks and no CHEAP/MEDIUM tasks.
Of these, 220 have verified intervals (18,268 bytes), 272 are partly unmapped
and 110 have no address anchor: **382/602 = 63.46%** have unverified boundaries.
The denominator is queued tasks, not all original functions or all code bytes.

The fresh census records overlapping candidates and capability gaps:

**261 tasks have multiple categories**, up to four each. Fractions must not be
summed. A reported capability class is not a forecast of how many promotions
one new tool will unlock. `blocker_census.py` explicitly keeps categories
research-only and does not reopen source budgets. This is already a useful
counterexample to one immutable root cause per function.

The camera example separates several dimensions: independent symbol/frame
evidence resolved two far calls; declaration order moved 11 BP-home sites;
a byte-result cast subsequently emitted 198 rather than 194 bytes and AL/CBW;
the 200-byte target still has a different return topology. The stack-home
mechanism does not explain the remaining branch/extent residue. Similarly,
`rect_adjust_from_point` reaches 31/33 exact instruction positions with only
two BP-2/BP-6 differences, but moving its temporary declaration produces
identical code. A register/stack pattern is descriptive until a source/context
intervention explains it. Sources: stunts-16/19 in the manifest.

## Transfer is already partly operational

The strongest claim that sibling lessons reached Stunts only as prose is
**REJECTED / TOO STRONG**. Current implementation includes:

- `blocker_census.py`: fresh context-qualified, multi-category observations;
- `tu_context.py`: frozen target body, ordered predecessor/successor snippets,
  full OMF artifacts, target byte/fixup groups and public/segment metadata;
- `audit_function_extents.py`: an Empires-inspired entry-reachability review,
  with four suspect intervals documented among 234 scanned intervals;
- native source/input guards, serial promotion, historical LINK differential
  fixtures, structured mismatch families and bounded hypothesis batches.

`vector_op_unk` is a concrete frontier improvement: the imported 94-byte extent
contains nine bytes after RETF starting another prologue. The checker does not
automatically trim it; alternate entries/data remain possible. This prevents
spending source-search effort on an unproven extent. It is a method/tool
transfer, not proof that Empires' compiler mechanism applies.

The new TU tool has both positive and negative controls. A 62-byte exact
rectangle is unchanged with a known neighbor before or after it; its offset
moves by 52 bytes with the predecessor. Conversely an unchanged synthetic
16-byte target body changes call bytes and fixup obligations when its helper
changes from external to a same-TU static predecessor. The first version of
that fixture failed compilation and is retained separately from the corrected
two-output result. These are compiler-context observations; strict acceptance
is explicitly NOT_EVALUATED. Public-bounded windows may include private code.
Sources: stunts-05/06/07/09.

What remains missing is narrower: independently supported original data/TU
topology and production support for additional self-relative, frame and
multi-public contributions. The binder intentionally requires one public at
zero and no unowned initialized/BSS contribution. Generalizing an MSC7 selector
pool or Empires compact-model frame rule would violate those obligations.

Highest-leverage candidate transfers are therefore: (1) revalidate a few
historical blockers against fresh profiles/evidence before repeating source
search; (2) complete one required historical LINK differential and original
symbol/ownership proof, then extend only that native binder mode; (3) give TU
probes protected-neighbor and complete-contribution accounting before treating
equal target windows as a composable recovery. These are experiments and native
capabilities, not shared-library extraction projects. A full scaffold composer
is premature without enough original topology evidence.

## Locality, source priors and stage confounding

The small source edit in `shape3d_init_shape` is relatively local and predictive:
removing a far-pointer alias removes its four-byte frame, restores the observed
argument reads and contracts 190 to 172 bytes for a strict promoted contribution.
This is evidence for a tractable local response under MSC5.10, not that old
compilers are uniformly well-conditioned. The camera and synthetic TU controls
show multiple dimensions and nonlocal context even in this compiler family.

Source priors also fail: the Restunts hint's first `rect_intersect` comparison
uses `<=`, while pristine control flow requires `<`; its paint-count field is
too wide for the byte store in `shape3d_init_shape`. Both were corrected using
machine evidence before strict recovery. An LLM/historical C hint does not
replace decoding or width/branch proof.

Historical status blobs show C bytes **252 → 328 → 408** while HYBRID_EXACT was
preserved and raw initialized bytes **199,023 → 198,947 → 198,867** decreased.
The later live status reports 834 C bytes and 198,441 raw bytes. Thus an exact
hybrid artifact plus monotonic owner substitution already exists in Stunts;
that invariant alone does not explain Empires' eventual source closure.
Stunts still lacks a broad verified frontier. Commit authors are user identities;
commit counts cannot identify which model supplied the work or its cost.

**Next falsifier:** preregister a small verified-boundary cohort with specific
old blockers, rerun current evidence classification without source edits, then
test one discriminating profile/TU/binding change per compatible subgroup.
Count revised observations, newly admissible work and actual native promotions
separately. If fresh classification exposes no actionable differences, a larger
taxonomy has not earned its maintenance cost.
