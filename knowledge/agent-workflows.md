# Agent search, routing and economics

**GENERIC METHOD.** A strict external oracle can judge acceptance independently
of an agent's confidence. It permits bounded source proposals to be evaluated
cheaply, provided the verifier covers the relevant bytes/bindings/layout and
the agent cannot weaken it. This does not make all cheap-model search productive
or make the verifier complete by definition.

Empires' finite card queue and SimAnt's attempt/variant caps are operational
gates. Stunts explicitly separates budget-censored, search-converged,
tooling-blocked and evidence-blocked outcomes. Do not translate a retry limit
into a statement about model capability. Sources: project grinder/factory and
Stunts worker/endurance records in the [dossiers](comparison.md).

**PROJECT FACT — Stunts routing pilot.** Four matched high-reasoning pairs had
strict receipts for two prequalified replays in both arms; neither model solved
the two unresolved cases. Recorded Standard-equivalent direct-worker scenarios
were $5.21717 Astra and $0.08130442 Luna; root supervision was $26.25143 plus
unpriced review traffic. These are archived scenario calculations, not current
model prices. Omitted-profile and parser/tool events must not count as model
failure; unresolved runs did not exhaust the 15-hypothesis/20-process cap.
No new C bytes or Astra-only class were established. Source: Stunts
`recovery/evaluation/model-routing/decision.md` and results, pinned/hashes in
[Stunts records](../research/stunts/records.json).

**PROJECT FACT — Stunts batching pilot.** On one target, a batch used 23% fewer
requests, 9% less wall time and 15% less direct-worker scenario cost, but yielded
two unique outputs versus four sequentially and neither arm strictly matched.
Candidate sets differed and batch identities were a subset of sequential
identities. This supports neither a universal batch size nor a throughput claim.
Source: `batching-decision.md` in the same evaluation directory.

**WORKING HYPOTHESIS.** A weak compiler gradient may explain why additional
reasoning/variants fail to improve some unresolved Stunts cases: source changes
either collapse or move unrelated dimensions. This is not evidence that the
compiler has no useful gradient everywhere. Measure novelty, predicted effects,
oracle dimensions and next-test decisions before accepting that explanation.

**GENERIC METHOD.** Keep a worker handoff small: baseline/context IDs, one
target, strict command/proof contract, surviving mismatch dimensions, bounded
independent hypotheses, known negative results, protected neighbors and stop
rule. Keep full artifacts elsewhere and reference them. Charge supervisor,
handoff, cached input, output and review costs to the same experimental cohort.

**WORKING HYPOTHESIS.** Route stronger reasoning to repeated blocker classes,
ABI/context discovery and deterministic tool improvements, while cheaper workers
run well-bounded tests. Empires' supervisor policy and SimAnt's factory show the
process split; Stunts does not yet provide a large controlled routing study.

Repeated diagnosis, identity grouping and attempt packaging are suitable for
deterministic tools. Compiler experiments may be much cheaper than another
reasoning round in a given setup—SimAnt's local service benchmark motivates
measurement—but compare complete costs before asserting this elsewhere.
